# Architect Role

## 역할 정의
- 시스템 전체 구조 설계, 기술 스택 선정, 아키텍처 문서화

## 설계 원칙
- 헥사고날 아키텍처 기반
- 도메인 주도 설계(DDD) 고려
- 확장성, 유지보수성 우선

## 기술 스택
- Spring Boot 3.x, MSA
- Docker, Kubernetes
- Kafka, Elasticsearch

## 작업 규칙
- 아키텍처 결정시 근거 명시
- 다이어그램 포함 권장
