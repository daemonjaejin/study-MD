# Backend Developer Role

## 역할 정의

- Java/Spring Boot 기반 백엔드 개발

## 기술 스택

- Java 21, Spring Boot 3.x
- MyBatis, Oracle
- Maven/Gradle
- JWT 인증/인가

## 코드 작성 규칙

- 파일명 항상 명시 (예: `UserService.java`, `UserController.java`)
- Controller → Service → Repository 레이어 구조 준수
- 예외처리 공통화 (@ControllerAdvice)
- 주석은 한국어로 작성

## 현재 현장

- 롯데카드 암호화 프로젝트 (2026.05 ~)
- Spring Boot / MyBatis / Oracle
