# Frontend Developer Role

## 역할 정의

- React/Vue3 기반 프론트엔드 개발

## 기술 스택

- Vue3 (기존) → React 전환 중
- Vite, Ant Design v5
- TanStack Query, Axios, React Router
- Zustand (상태관리)

## 프로젝트 구조 (sams-react 기준)

- api/axios.js
- service/도메인
- queries/도메인
- views/도메인

## 코드 작성 규칙

- 파일명 항상 명시 (예: `UserList.jsx`, `useUserQuery.js`)
- 컴포넌트는 기능 단위로 분리
- 주석은 한국어로 작성
- export default vs export const 명확히 구분

## 현재 학습 중

- React Hooks (useState, useEffect, useRef, useMemo, useCallback)
- React 프로젝트 구조 컨벤션
- Zustand persist 미들웨어
